# <img src="docs/imgs/RIP_Bozo.webp" width="40"> RipBozo

**Put your money where your mouth is... or rather, your time.**

RipBozo is a Twitch integration that turns chat arguments into high-stakes wagers. Users challenge each other to simple games, and the loser gets banned from the channel for the wagered amount of time.

### 🎮 The Core Loop
**Challenge** (`!challenge`) &rarr; **Game** (Webapp) &rarr; **Ban** (Twitch API)
